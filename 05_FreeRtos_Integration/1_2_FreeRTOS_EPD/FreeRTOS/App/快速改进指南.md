## 第1步：分离数据类型定义（15分钟）

### 问题
- `Key_RTOS.h` 混合了按键定义和显示定义
- 显示模块需要 `DispCmd`，但定义在按键文件里

### 解决方案：创建独立的类型定义文件

#### 1.1 创建 `AppTypes.h`

```c
// FreeRTOS/App/AppTypes.h
#ifndef _APP_TYPES_H_
#define _APP_TYPES_H_

// 画面状态枚举
typedef enum {
    SCREEN_MAIN_MENU,       // 主菜单
    SCREEN_READING_SEL,     // 阅读-页码选择
    SCREEN_READING_VIEW,    // 阅读-内容显示
    SCREEN_CALENDAR         // 日历模式
} CurrentScreen;

// 显示命令类型
typedef enum {
    DISP_CMD_NONE,
    DISP_CMD_MENU_SEL_CHANGE,       // 切换主菜单选中项
    DISP_CMD_ENTER_CALENDAR,        // 进入日历
    DISP_CMD_ENTER_READING_SEL,     // 进入阅读选择
    DISP_CMD_READING_PAGE_CHANGE,   // 切换页码
    DISP_CMD_ENTER_READING_VIEW,    // 进入阅读内容
    DISP_CMD_BACK_TO_READING_SEL,   // 返回阅读选择
    DISP_CMD_BACK_TO_MAIN           // 返回主菜单
} DispCmdType;

// 显示命令结构
typedef struct {
    DispCmdType cmd;
    int16_t param;
} DispCmd;

#endif
```

## 第2步：统一状态管理（20分钟）

### 问题
- `g_MenuSel` 定义在 `Display.c`，但 `Key_RTOS.c` 需要访问
- 状态分散在不同文件，难以管理

### 解决方案：集中到 Screen_state 模块

#### 2.1 扩展 `Screen_state.c`

```c
// Screen_state.c
#include "Screen_state.h"
#include "AppTypes.h"

// 完整的应用状态
typedef struct {
    CurrentScreen screen;
    uint8_t menuSel;           // 主菜单选中项
    uint16_t readingPage;      // 阅读页码
} AppState_t;

static AppState_t g_AppState = {
    .screen = SCREEN_MAIN_MENU,
    .menuSel = 0,
    .readingPage = 1
};

static SemaphoreHandle_t g_StateMutex = NULL;

// 初始化
void ScreenState_Init(void) {
    g_StateMutex = xSemaphoreCreateMutex();
    configASSERT(g_StateMutex != NULL);
    g_AppState.screen = SCREEN_MAIN_MENU;
    g_AppState.menuSel = 0;
    g_AppState.readingPage = 1;
}

// 获取当前画面
CurrentScreen ScreenState_Get(void) {
    CurrentScreen ret = SCREEN_MAIN_MENU;
    if (g_StateMutex && xSemaphoreTake(g_StateMutex, pdMS_TO_TICKS(10)) == pdTRUE) {
        ret = g_AppState.screen;
        xSemaphoreGive(g_StateMutex);
    }
    return ret;
}

// 设置当前画面
void ScreenState_Set(CurrentScreen newScreen) {
    if (g_StateMutex && xSemaphoreTake(g_StateMutex, pdMS_TO_TICKS(10)) == pdTRUE) {
        g_AppState.screen = newScreen;
        xSemaphoreGive(g_StateMutex);
    }
}

// 获取菜单选中项
uint8_t AppState_GetMenuSel(void) {
    uint8_t ret = 0;
    if (g_StateMutex && xSemaphoreTake(g_StateMutex, pdMS_TO_TICKS(10)) == pdTRUE) {
        ret = g_AppState.menuSel;
        xSemaphoreGive(g_StateMutex);
    }
    return ret;
}

// 设置菜单选中项
void AppState_SetMenuSel(uint8_t sel) {
    if (g_StateMutex && xSemaphoreTake(g_StateMutex, pdMS_TO_TICKS(10)) == pdTRUE) {
        g_AppState.menuSel = sel;
        xSemaphoreGive(g_StateMutex);
    }
}

// 获取阅读页码
uint16_t AppState_GetReadingPage(void) {
    uint16_t ret = 1;
    if (g_StateMutex && xSemaphoreTake(g_StateMutex, pdMS_TO_TICKS(10)) == pdTRUE) {
        ret = g_AppState.readingPage;
        xSemaphoreGive(g_StateMutex);
    }
    return ret;
}

// 设置阅读页码
void AppState_SetReadingPage(uint16_t page) {
    if (g_StateMutex && xSemaphoreTake(g_StateMutex, pdMS_TO_TICKS(10)) == pdTRUE) {
        g_AppState.readingPage = page;
        xSemaphoreGive(g_StateMutex);
    }
}
```

## ? 完成后的效果

1. **每个文件职责明确**
   - `AppTypes.h` - 类型定义
   - `Key_RTOS.*` - 按键处理
   - `Display.*` - 显示控制
   - `Screen_state.*` - 状态管理

2. **依赖关系清晰**
   - 所有模块都依赖 `AppTypes.h`
   - 通过 `Screen_state.h` 访问状态
   - 没有循环依赖

3. **易于测试和维护**
   - 每个模块可以独立测试
   - 状态变更集中管理
   - 增加新功能更容易
